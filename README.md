# КОКОС IV — интерактивная 3D-панель

Самостоятельный демонстрационный интерфейс умного дома, восстановленный по дизайн-проекту КОКОС IV. Проект отделён от референсного объекта: геометрия, помещения, мебель, материалы и устройства описаны собственным manifest.

**Онлайн-версия:** <https://ambboy.github.io/kokos-iv-smart-home/>

## Возможности

- интерактивная Three.js-сцена с обзором, фокусом на помещениях и свободным полётом;
- дневной, вечерний и отсутствующий сценарии;
- физически заметное управление светом, шторами и климатом;
- 59 визуальных позиций света по подтверждённому плану;
- семь витражей как реальные проёмы с отдельными рамами и стеклом;
- debug-режим с границами, дверными дугами, overlay и коллизиями;
- адаптивный интерфейс для desktop, планшета и мобильного экрана.

Все команды устройств работают в явно обозначенном демонстрационном режиме. Реальных MQTT-топиков, адресов устройств и commissioning-данных в проекте нет.

## Локальный запуск

```bash
npm ci
npm run dev
```

Полная проверка:

```bash
npm run validate
npm run build
npm run check
```

Источники, допущения и статусы достоверности описаны в [ARCHITECTURE.md](ARCHITECTURE.md), результаты проверок — в [QA.md](QA.md).

## Публикация

Push в ветку `main` запускает проверку и публикацию production-сборки на GitHub Pages через `.github/workflows/deploy-pages.yml`.
